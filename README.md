# bird · 2D 弹弓物理游戏

基于 Unity 2D 物理系统开发的弹弓投射游戏。玩家拖拽小鸟调整发射方向和力度，松开鼠标后利用弹簧力完成投射，通过碰撞击破目标与障碍物，在有限的小鸟数量内完成挑战。

项目整合了**拖拽输入、弹簧发射、碰撞反馈、小鸟轮换、胜负判定和星级结算**，并使用弹弓皮筋、飞行拖尾、镜头跟随与音效表现投射过程。

`Unity` · `C#` · `Rigidbody2D` · `SpringJoint2D` · `LineRenderer` · `Coroutine`

## 核心玩法

| 功能 | 说明 |
| --- | --- |
| 拖拽瞄准 | 将鼠标屏幕坐标转换为世界坐标，并限制最大拉伸距离 |
| 弹弓发射 | 拖拽时切换刚体状态，松开后由弹簧驱动，再解除弹簧连接进入飞行 |
| 皮筋表现 | 使用两条 LineRenderer 实时连接弹弓支点和小鸟 |
| 飞行表现 | 发射时启用拖尾，碰撞时清除拖尾，镜头平滑跟随横向位置 |
| 碰撞反馈 | 根据相对碰撞速度区分受损与销毁，搭配贴图、音效和特效反馈 |
| 小鸟轮换 | 管理待发射小鸟列表，完成一次投射后衔接下一只小鸟 |
| 胜负结算 | 根据剩余目标和小鸟数量显示胜利或失败界面 |
| 星级展示 | 结合剩余小鸟数量，通过协程依次展示结算星星 |
| 流程控制 | 支持关卡入口、重新挑战和返回关卡选择 |

## 操作方式

1. 在关卡选择界面进入游戏。
2. 按住待发射的小鸟并向后拖动，调整角度与拉伸距离。
3. 松开鼠标发射，观察投射轨迹和碰撞结果。
4. 使用后续小鸟继续清除目标，通过结算界面重新挑战或返回选择界面。

## 技术实现

### 输入与物理状态切换

通过 `OnMouseDown`、`OnMouseUp` 驱动拖拽与释放流程。拖拽时手动更新小鸟位置并限制拉伸半径；释放时恢复刚体物理模拟，短暂保留 `SpringJoint2D` 的弹力，再断开连接形成自由飞行。

### 碰撞与表现反馈

使用 `Collision2D.relativeVelocity.magnitude` 判断碰撞强度。不同阈值对应受损贴图或目标销毁，销毁时生成特效和分数提示。弹弓皮筋、拖尾与镜头跟随共同提供发射方向和运动状态的视觉反馈。

### 关卡状态管理

`Gamemanager` 维护小鸟和目标列表，统一处理小鸟启用、发射位置恢复、轮换及胜负判断。结算星星使用协程依次显示，重新挑战和返回入口通过场景切换完成。

## 运行方式

- **Unity 版本**：`2021.1.18f1c1`
- **关卡选择场景**：`Assets/Scenes/01--level.unity`
- **游戏场景**：`Assets/Scenes/SampleScene.unity`

1. 克隆仓库，通过 Unity Hub 打开仓库根目录的 Unity 工程。
2. 使用对应版本编辑器完成资源导入。
3. 打开 `01--level` 并点击 Play，通过关卡按钮进入游戏；也可打开 `SampleScene` 直接体验发射玩法。
4. 构建时保持现有场景索引，以便重新挑战与返回按钮正确跳转。

| Build Index | 场景 |
| ---: | --- |
| 0 | `00--loading` |
| 1 | `01--level` |
| 2 | `SampleScene` |
